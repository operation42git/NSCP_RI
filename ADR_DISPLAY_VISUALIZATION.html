Summary

ADR Display Characteristics:

  • Always Visible: ADR section is always displayed, regardless of whether dangerous goods data exists in the XML
  • All Fields Shown: All ADR fields are always displayed, showing "—" when data is not available
  • No Duplicates: Fields already shown in ECMR section (consignor, consignee) are not duplicated in ADR section
  • ADR-Specific Only: Only dangerous goods specific fields are shown, not general transport/equipment data
  • Multiple Sources: Data can come from either consignment/dangerousGoods (consignment level) or consignment/includedConsignmentItem/transportDangerousGoods (item level)

Field Mapping Process:

  1. XML data from consignment-common.xml is parsed by ECMRParserService
  2. ADR data is extracted from both consignment-level and item-level dangerous goods elements
  3. parseADRData() method creates ADRData object with ADRItem array
  4. Frontend component displays all ADR fields using field-group format matching ECMR section
  5. All fields are always visible, displaying "—" when XML data is missing

Key ADR Fields:

  • Proper Shipping Name: Required ADR field - proper shipping name of dangerous goods
  • UN Number (uNDGID): UN identification number for the dangerous substance
  • Hazard Classification: Classification ID, Category Code, and Type Code
  • Packaging & Restrictions: Packaging danger level, tunnel restrictions, limited quantity codes
  • Temperature Requirements: Control and emergency temperature specifications
  • Radioactive Material: Special section for radioactive materials with isotope and activity details
  • Physical Properties: Density, melting point, weights, volumes
