3. Implementation Details

How the XSLT transformation works

Display Flow:

  1. UIL Search: User enters Dataset ID, Gate ID, and Platform ID
  2. Results Table: Shows search results with Request ID, Gate ID, Dataset ID, Platform ID, Status, and Action buttons
  3. Open Action: When clicking "Open" on a COMPLETE result:
    • XML data is decoded from base64
    • XSLT stylesheet is loaded from /assets/xslt/eCMR.xslt
    • XSLTProcessor transforms the XML using the XSLT template
    • Resulting HTML is opened in a new window

Key Files:

  • Component: portal-mock/src/app/pages/uil-search/u il-search.component.ts
  • Template: portal-mock/src/app/pages/uil-search/u il-search.component.html
  • XSLT: portal-mock/src/assets/xslt/eCMR.xslt
Important Note: This XSLT version has limited field mapping. Many fields are empty or contain hardcoded sample data. Only basic address fields (Fields 1-4, 16) and total weight/volume are mapped from the XML. The goods table contains hardcoded sample data rather than actual XML values.
